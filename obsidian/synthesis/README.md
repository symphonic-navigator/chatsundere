# Project Synthesis — Idea Vault

This folder collects ideas and findings for **Project Synthesis**: giving personas
*write* access to their external knowledge stores — synthetic knowledgebase
documents, self-curated memory bodies, and (growing out of those) a skill-like
system of self-authored, on-demand documents.

This is deliberately **two levels below** the usual workflow: no Lyra brief
exists yet. Notes here are raw material — vibing sessions between Chris and Liz,
findings, tensions, sketches. When the shape firms up, the output graduates into
a brief and then a spec under `superpowers/specs/`.
