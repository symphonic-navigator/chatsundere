# Knowledge

Assign knowledge-base libraries to this persona so it can draw on your curated content during conversations.

## Library Assignment

Each toggle row represents one of your knowledge libraries. Active libraries are injected as context when this persona is used in a chat.

- **Tick a library** to enable it for this persona.
- **Untick a library** to remove it.

Changes take effect immediately — no save button required.

## NSFW Libraries

Libraries marked as NSFW are only shown here when this persona is configured as an adult persona (set in **Instructions**). SFW personas never see or inherit NSFW libraries.

## Creating Libraries

If you have no libraries yet, head to **My Knowledge** to create one. Libraries are built from documents you upload or import there.
