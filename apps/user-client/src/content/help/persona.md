# Persona

A **persona** is an AI companion with its own name, instructions, model, and personality. Everything you set here shapes how the persona speaks and behaves in your chats.

## Creating a persona

The only required field is a **name** — that is what unlocks the Create button. Everything else (instructions, model, avatar, tagline, behaviour, voice, and so on) can be filled in after creation from the persona's own hub page, where every change saves automatically.

## Coming from Chatsune?

Use the **Import** section to bring across a persona export. In create mode the import always fills in the name, tagline, and instructions. Any chats and memories in the export are staged and written the moment you click Create.

## After you create

You land on the persona hub, where you can:

- **Chat** — start a new conversation or continue the most recent one.
- **Edit** any field — each sub-page saves automatically as you type; there is no Save button.
- **Avatar, voice, model, mindspace** — all configurable from the hub.

The persona is ready to chat as soon as it has a name and a model selected.
