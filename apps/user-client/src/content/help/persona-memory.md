# Memory

Manage what this persona remembers about you and your conversations.

## Remembering

The **Remembering** toggle controls whether this persona builds a memory of you at all.
This is a **persona-wide setting** — it applies to every chat you have with this companion,
not just the current one.

## Memory Instructions

Tell the persona what kinds of things to pay attention to when building your memory:
projects you work on, topics you care about, people you mention. Leave empty to let the
persona decide what is worth remembering.

## Pending Memories

Journal entries extracted from your chats that are waiting for your review.

- **Commit** keeps the entry and moves it to the consolidation queue.
- **Edit** lets you correct the wording before committing.
- **Delete** discards the entry (with a five-second undo window).

## The Memory Itself

The consolidated text the persona carries into every conversation. You can edit it
directly or restore an earlier version from the version list below it.

## Learn / Consolidate

Available on the chat path only. **Learn from this chat** extracts new facts from the
current conversation. **Consolidate now** merges all committed entries into the memory
body and clears the queue.
