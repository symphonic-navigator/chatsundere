# Chat Artefacts

Artefacts generated during **this chat** — the conversation you have open right now.

## What lives here

Whenever a companion produces a discrete output — a code file, a document, an image, a
table — it is captured as an artefact and appears in this list. You can view, copy, or
download each one without scrolling back through the conversation to find it.

## Scope

Artefacts here belong exclusively to this chat. They are not mixed in with artefacts from
other conversations. When you start a new chat, it begins with its own clean artefact list.

## Distinct from My Treasury

**My Treasury** (reached from the main menu) holds artefacts you have explicitly saved to
your global collection across all chats. This page is the working set for the current
conversation — the scratchpad, not the archive.
