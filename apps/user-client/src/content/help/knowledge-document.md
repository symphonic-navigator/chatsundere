# Knowledge Document

A knowledge document is a single note your companions can retrieve when it is
relevant to the conversation. Write anything here — an essay, a set of bullet
points, a code snippet with commentary — in plain Markdown.

## Saving

Give the document a **title** and fill in the **content**, then tap **Save**.
The document is queued for indexing immediately; the status badge in the library
updates once embedding is complete.

## Trigger phrases

Trigger phrases are hints that tell the companion when to look up this document.
Add a phrase for each situation you expect to invoke the note — for example,
`my dietary restrictions` or `project deadlines`. The companion matches against
these loosely, so single keywords work as well as full sentences.

## Let the companion trigger this too

Once you have added at least one trigger phrase, you can enable **Let the
companion trigger this too**. When active, the companion may surface this
document proactively during conversation — not only when a phrase is detected
by the retrieval engine. The toggle stays disabled until at least one trigger
phrase is saved.

## Editing and re-indexing

You can update the title or content at any time. Tapping **Save** after an edit
clears the old index entry and queues the document for re-indexing, so the
companion always searches the latest version. The document remains available in
the library while re-indexing is in progress.
