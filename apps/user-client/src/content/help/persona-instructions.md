# Instructions

Configure what makes this persona who they are.

## Chatsundere Tonality

The curated Chatsundere voice — open, expressive, and uncensored on topics. Enabled by default for all personas. Turn it off if you want a plainer, more neutral style.

## Adult Persona

Marks this persona as adult-oriented, unlocking explicit content in its system prompt. Hidden automatically when sanitised mode is active in your settings.

## Custom Instructions

The core of the persona — write who they are, how they think, and how they speak. This field is required before the persona can start a chat.

## What the Model Knows About You

An optional per-persona override for your global About Me text. Leave empty to use the global version set in **My Settings → You**. Fill it in to give this persona a different picture of you.
