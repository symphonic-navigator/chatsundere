# My Knowledge

Your Knowledge room is a personal library system that gives your companions
memory beyond the conversation. You organise it into **libraries** — each one a
focused collection of notes on a topic — and your companions can search across
them when answering questions.

## Libraries

Each library acts as a folder of documents. Create one per topic, project, or
context you want a companion to draw on: a research bibliography, a set of
meeting notes, a personal wiki. There is no limit to how many you can have.

## Adult libraries

Libraries that contain adult material can be flagged as **NSFW only**. They are
hidden in sanitised mode and surfaced only when NSFW mode is active, so you
never have to shuffle content around by hand.

## Creating and importing

Tap **+ Add** to start a new library, or import an existing collection from
Chatsune if you are migrating. Once a library exists, open it to upload
documents or write new ones directly.
