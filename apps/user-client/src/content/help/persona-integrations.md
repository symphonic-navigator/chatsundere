# Integrations

Per-persona tool access — choose which MCP servers this persona may use.

## MCP Servers

MCP (Model Context Protocol) servers extend what this persona can do: web search, code execution, file access, and more. Each server is enabled or disabled globally in **My Settings → MCP Servers**.

Here you can override that global setting on a per-persona basis:

- **Default** — follows the server's own "on by default" setting.
- **On** — force-enables this server for the persona, regardless of the global default.
- **Off** — force-disables this server for the persona, even if it is on by default.

If no MCP servers are configured, head to **My Settings → MCP Servers** to add one.
