# Knowledge Library

This page shows a single library and lets you manage everything about it —
its name, description, and the documents it holds.

## Name and description

Changes to the library's name and description are saved automatically as you
type. There is no Save button to forget.

## Adult content flag

If the library contains adult material, you can mark it **NSFW only** here.
The option is available only when NSFW mode is active, which keeps the setting
from being changed by accident in a shared or public setting.

## Adding documents

Tap **Add ▾** to open the add menu. Choose **Upload files** to import one or
more `.md` or `.txt` files from your device, or choose **New document** to open
a blank editor and write or paste content directly in Chatsundere. Both paths
land in the same library.

## Status badges

Each document shows a badge indicating its current embedding state:

- **Pending** — the document is queued; embedding has not started yet.
- **Embedding…** — the document is being embedded; the companion cannot search
  it yet.
- **Ready** — embedding is complete and the companion can use the document.
- **Failed** — embedding failed; open the document and tap **Retry** to try
  again.
