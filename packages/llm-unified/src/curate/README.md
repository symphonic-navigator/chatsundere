# curate — model-support factory

Maintainer CLI. **Not shipped to clients** (not exported from the package index).

## Commands

```
bun run curate provider list
bun run curate model list [provider]
bun run curate model template <provider:slug>...   > models/<id>.yaml
bun run curate model build models/<id>.yaml [--verify]
bun run curate model report <model.yaml>
bun run curate model verify <ref> | --all        # not yet implemented
```

## Flow

1. `model template nano-gpt:zai-org/glm-6 novita:zai-org/glm-6 > models/glm-6.yaml`
   — both offerings prefilled; fill in the judgement fields (freedom, trust,
   context recommended/max).
2. `model build models/glm-6.yaml` — per offering: probe the target, capture
   real fixtures, GLM-5.1 writes the adapter, it is validated **structurally
   against the fixtures** (no baseline) with self-repair. Writes the adapter as a
   sibling `.ts`, the generated `built:` block back into the YAML (human comments
   preserved), and a deterministic report to `obsidian/models/<id>.md`.
3. Review the generated adapter `.ts` in your editor; test in the app; commit.

Requires `NANO_GPT_API_KEY` (see `packages/llm-unified/.env.example`). Model YAMLs
live in `packages/llm-unified/models/`.

## What lives where

- Human-curated: identity (`canonical`), the marriage (`offerings`), and the
  judgement fields. The capability gate requires each offering to deliver the
  canonical's T/R/V `requiredCaps`.
- Machine-generated by `build`: the per-offering adapter `.ts` and the `built:`
  block (measured profile + verdict). Never hand-edited.

Not yet built (deferred): signing/feed delivery, the Ollama catch-all adapter,
`model verify` drift detection, the `--verify` post-build re-probe (validation
already runs inside the synthesis loop; the separate confirmation pass is a
follow-up), `model list` grouping/badges for non-nano-gpt providers, and a
per-provider API key (today a single `NANO_GPT_API_KEY` serves analyzer +
target — split into `targetApiKey` before building a differently-keyed
provider).
