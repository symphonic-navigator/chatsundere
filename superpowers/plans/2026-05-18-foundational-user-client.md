> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Date:** 2026-05-18
**Spec:** `superpowers/specs/2026-05-18-foundational-auth-layer-design.md` (sections §1–§2, §3, §3.10, §3.11, §4, §6.1.1, §7, §8.4, §9, §12 ADRs).
**Related ADRs:** 0005 (PRF required), 0008 (local-first identity), 0009 (operator migration), 0010 (recovery challenge-response), 0013 (IndexedDB integrity HMAC), 0014 (synced-passkey AAGUID policy), 0016 (local-first biometric unlock via WebAuthn PRF), 0017 (path-based routing default).
**Related deferrals:** `obsidian/insights/security-deferrals.md` — the refresh-reuse user-facing notification (2026-05-18) is explicitly deferred to phase 1; this plan only adds a comment in the fetch wrapper. L-B3 (rate-limit counts successes) becomes user-visible here and Task 3 surfaces the matching banner copy.

**Goal:** Build `apps/user-client` — the local-first PWA that owns every UX flow specified in §7 of the spec: onboarding, local login (passphrase / biometric / recovery), settings (account, authentication methods, server linking, about), QR-driven invitation linking, OPAQUE registration, WebAuthn-PRF biometric enrolment, passphrase change with staging-slot reconciliation, recovery-key regeneration, recovery-only sign-in, server-account self-deletion. All cryptography is delegated to `@chatsundere/crypto`; this app is a coordinator. Mobile-first at 380 px viewport, single `lg` breakpoint, Instrument Serif headings, opulent feel, organic motion variation, inline-marker pills.

**Architecture:** React 18 + TypeScript (strict) on Vite 6. Routing via React Router. State split: TanStack Query for any server interaction (auth-aware fetch wrapper handles 401 refresh + 429 retry); Zustand for client-only state (current `MasterKeySession` reference, connectivity badge, staging-reconciliation status, service-worker update banner). Form validation via Valibot (per CLAUDE.md §4). Tailwind v4 with a Tailwind tokens layer for the opulent palette. PWA shell via `vite-plugin-pwa` + Workbox: precache the static bundle, cache-first for fonts, NetworkOnly for `/v1/`. WebAuthn PRF biometric registration uses raw `navigator.credentials.create()` against the crypto package's PRF input salt; for non-PRF authenticators registration is refused per ADR 0005. QR scanning via the in-browser `BarcodeDetector` API where available, with a `qr-scanner` library fallback for Safari and older Android Chrome.

**Squash boundary:** A single squashed commit titled `Add user-client PWA for foundational auth` once all tasks pass. Larissa does **not** audit this squash by default (CLAUDE.md §9: frontend-only changes skip the gate). My judgement call — if anything in this work ends up touching `packages/crypto` (it should not), pull Larissa in for that single hunk.

**Pre-requisite squash (separate, before this one):** a small `packages/crypto` extension adds a `MasterKeySession` method for PRF wrapping — see the "Pre-Squash D crypto helper" note in Task 10 below. That squash is Larissa-audited on its own. This plan assumes the helper exists at implementation time.

**Out of scope for squash D (explicit):** Chat surface, personas, sync, proxy, push notifications, multi-account, account import, drag-and-drop, server-rendered routes, tablet-specific designs, i18n machinery (en-GB only), light/dark toggle (system-preference only), Storybook, visual-regression infra.

**Decision (Chris-approved):** `qr-scanner` is the chosen fallback library. Single-purpose (QR only), MIT-licensed, no native dependencies, works in iOS Safari ≥ 14. `@simplewebauthn/browser` is intentionally **not** added: the spec's PRF flow needs the raw `extensions.prf.eval.first` field, which `@simplewebauthn/browser` does not surface as a first-class parameter. The crypto package already exposes `PRF_INPUT_SALT`; the user-client uses `navigator.credentials.create()`/`get()` directly. If during implementation a subagent finds the raw API ergonomics intolerable, request a divergence ADR before pulling the dependency.

```typescript
import { create } from 'zustand';

export type BootPhase =
  | { kind: 'pending' }
  | { kind: 'runtime_failure'; missing: string[] }
  | { kind: 'db_failure'; error: string }
  | { kind: 'ready'; staging: StagingOutcome };

export type StagingOutcome =
  | { kind: 'none' }
  | { kind: 'rolled_back' }    // Pending swap aborted; user is informed.
  | { kind: 'completed' };     // Silent finish on next boot.

interface BootState {
  phase: BootPhase;
  set(phase: BootPhase): void;
}

export const useBootStore = create<BootState>((set) => ({
  phase: { kind: 'pending' },
  set: (phase) => set({ phase }),
}));
```

```typescript
// apps/user-client/src/boot/runtime-check.ts
// SPDX-License-Identifier: AGPL-3.0-only
import { assertRuntimeSupport } from '@chatsundere/crypto';

const MISSING_PATTERN = /Missing required runtime APIs:\s*(.+)$/i;

/**
 * Wraps assertRuntimeSupport() and translates its throw into a structured
 * error suitable for the boot store. Per spec §3.12 we refuse to continue
 * — there is no silent fallback. The boot screen names the missing API so
 * Chris can triage on a real device.
 */
export function checkRuntime(): { ok: true } | { ok: false; missing: string[] } {
  try {
    assertRuntimeSupport();
    return { ok: true };
  } catch (e) {
    const message = e instanceof Error ? e.message : String(e);
    // Crypto package throws with "Missing required runtime APIs: ..." — extract.
    const match = message.match(MISSING_PATTERN);
    const missing = match?.[1]?.split(',').map((s) => s.trim()) ?? ['unknown'];
    return { ok: false, missing };
  }
}
```

```typescript
// apps/user-client/src/boot/open-db.ts
// SPDX-License-Identifier: AGPL-3.0-only
import { openLocalDb } from '@chatsundere/crypto';

/**
 * Single IDB handle for the app lifetime. Stored module-scoped so route
 * components and Zustand stores can call getDb() without re-opening.
 */
let dbHandle: IDBDatabase | null = null;

export async function openDb(): Promise<IDBDatabase> {
  if (dbHandle) return dbHandle;
  dbHandle = await openLocalDb();
  return dbHandle;
}

export function getDb(): IDBDatabase {
  if (!dbHandle) throw new Error('IDB not opened — call openDb() during boot first');
  return dbHandle;
}
```

- [ ] **Step 4: Create `apps/user-client/src/boot/reconcile-staging.ts`**. Per spec §5.7 the three states are `pending` (silent rollback), `committed` (silent completion), and absent (no-op). Per spec §7.5 the user is informed only when a rollback occurred.

```typescript
// apps/user-client/src/boot/reconcile-staging.ts
// SPDX-License-Identifier: AGPL-3.0-only
import { reconcileStagingOnBoot, getStaging } from '@chatsundere/crypto';
import type { StagingOutcome } from '../state/boot.store.js';
import { getDb } from './open-db.js';

/**
 * Performs the crash-recovery reconciliation on boot. Returns the outcome
 * so the gate route can show the "previous passphrase change didn't
 * complete" banner if applicable. Spec §5.7, §7.5.
 */
export async function reconcileStaging(): Promise<StagingOutcome> {
  const db = getDb();
  const before = await getStaging(db);
  if (!before) return { kind: 'none' };
  await reconcileStagingOnBoot(db);
  const after = await getStaging(db);
  // Crypto contract: a 'committed' staging row is completed and deleted;
  // a 'pending' staging row is rolled back and deleted. Either way `after`
  // is null. We distinguish by the prior server_state.
  if (after !== null) {
    // Should not happen; treat as rolled_back to fail safe.
    return { kind: 'rolled_back' };
  }
  return before.server_state === 'committed' ? { kind: 'completed' } : { kind: 'rolled_back' };
}
```

### Task 3: TanStack Query + auth-aware fetch wrapper + 429 handling

**Files:**
- Create: `apps/user-client/src/lib/queryClient.ts`.
- Create: `apps/user-client/src/lib/fetch.ts`.
- Create: `apps/user-client/src/lib/server-client.ts`.

The fetch wrapper carries three responsibilities (per spec §8.4 and ADR 0011 endpoint set):

1. Injects the current `accessToken` from the session store as `Authorization: Bearer …` when present.
2. On a 401 from a bearer-authenticated call, attempts exactly one `/v1/token/refresh` and retries the original request. If the refresh itself fails, the session is closed and the gate routes back to login. (Per the 2026-05-18 refresh-reuse deferral: when the refresh returns `refresh_token.reuse_detected` we silently log out; surfacing a banner is deferred to phase 1 — note this with a comment, do **not** implement it.)
3. On a 429 with a `Retry-After` header, surfaces a structured error containing `retryAfterSeconds`. We do **not** auto-retry — login + recovery endpoints' rate-limits are user-visible per L-B3 deferral.

Cookies are sent automatically on the refresh-token endpoint because it is same-origin (or operator-deployed same-origin). `credentials: 'include'` is set on every request to the linked `base_url` so the refresh cookie reaches `/api/auth/v1/token/refresh`.

```typescript
// apps/user-client/src/lib/fetch.ts
// SPDX-License-Identifier: AGPL-3.0-only
import { useSessionStore } from '../state/session.store.js';

export class HttpError extends Error {
  constructor(
    readonly status: number,
    readonly code: string | undefined,
    message: string,
    readonly retryAfterSeconds?: number,
  ) {
    super(message);
    this.name = 'HttpError';
  }
}

export interface ApiFetchOptions extends Omit<RequestInit, 'body'> {
  baseUrl: string;
  path: string;             // e.g. '/auth/v1/me'
  json?: unknown;           // serialised as JSON; sets Content-Type
  authMode?: 'none' | 'bearer';
}

/**
 * Auth-aware fetch wrapper. The single happy-path call site for every server
 * round-trip in the user-client. Behaviour:
 *
 * 1. `authMode: 'bearer'` injects the Authorization header from the session
 *    store. On 401, attempts one /v1/token/refresh round-trip then retries.
 *    If the refresh fails the session is closed and 401 propagates.
 * 2. `authMode: 'none'` skips the Authorization header.
 * 3. 429 is surfaced as HttpError with retryAfterSeconds parsed from the
 *    Retry-After header (per spec §8.4). The caller decides whether to show
 *    a rate-limit banner — we never auto-retry because the affected
 *    endpoints (login, recovery) are user-driven and must not silently
 *    burn attempts.
 * 4. Refresh-reuse detection deferral (2026-05-18): when /v1/token/refresh
 *    returns `refresh_token.reuse_detected` we close the session silently.
 *    A user-facing banner is phase-1 scope.
 */
export async function apiFetch<T>(opts: ApiFetchOptions): Promise<T> {
  const url = new URL(opts.path, opts.baseUrl).toString();
  const init = buildInit(opts);
  let res = await fetch(url, init);
  if (res.status === 401 && opts.authMode === 'bearer') {
    const refreshed = await tryRefresh(opts.baseUrl);
    if (refreshed) {
      res = await fetch(url, buildInit(opts));
    }
  }
  if (!res.ok) {
    const code = await safeReadCode(res);
    const retryAfter = parseRetryAfter(res.headers.get('Retry-After'));
    throw new HttpError(res.status, code, `${res.status} ${res.statusText}`, retryAfter);
  }
  if (res.status === 204) return undefined as T;
  return (await res.json()) as T;
}

function buildInit(opts: ApiFetchOptions): RequestInit {
  const headers = new Headers(opts.headers);
  if (opts.json !== undefined) headers.set('Content-Type', 'application/json');
  if (opts.authMode === 'bearer') {
    const token = useSessionStore.getState().session?.accessToken;
    if (token) headers.set('Authorization', `Bearer ${token}`);
  }
  return {
    method: opts.method ?? (opts.json !== undefined ? 'POST' : 'GET'),
    headers,
    credentials: 'include',
    body: opts.json !== undefined ? JSON.stringify(opts.json) : undefined,
  };
}

async function tryRefresh(baseUrl: string): Promise<boolean> {
  try {
    const url = new URL('/auth/v1/token/refresh', baseUrl).toString();
    const res = await fetch(url, { method: 'POST', credentials: 'include' });
    if (!res.ok) {
      useSessionStore.getState().closeAndForget();
      return false;
    }
    const body = (await res.json()) as { access_token: string; expires_in: number };
    useSessionStore.getState().updateAccessToken(body.access_token);
    return true;
  } catch {
    useSessionStore.getState().closeAndForget();
    return false;
  }
}

function parseRetryAfter(value: string | null): number | undefined {
  if (!value) return undefined;
  const asInt = Number.parseInt(value, 10);
  if (Number.isFinite(asInt) && asInt > 0) return asInt;
  return undefined;
}

async function safeReadCode(res: Response): Promise<string | undefined> {
  try {
    const body = (await res.clone().json()) as { error?: { code?: string } };
    return body.error?.code;
  } catch {
    return undefined;
  }
}
```

```typescript
// SPDX-License-Identifier: AGPL-3.0-only
import type { ServerClient } from '@chatsundere/crypto';
import type {
  LinkOpaqueFinishRequest, LinkOpaqueFinishResponse,
  LinkOpaqueStartRequest, LinkOpaqueStartResponse,
  LinkPasskeyFinishRequest, LinkPasskeyFinishResponse,
  LinkPasskeyStartRequest, LinkPasskeyStartResponse,
  OpaqueLoginFinishRequest, OpaqueLoginFinishResponse,
  OpaqueLoginStartRequest, OpaqueLoginStartResponse,
  RecoveryFinishRequest, RecoveryFinishResponse,
  RecoveryStartRequest, RecoveryStartResponse,
} from '@chatsundere/shared-types';
import { apiFetch } from './fetch.js';

export const httpServerClient: ServerClient = {
  linkOpaqueStart: (req, baseUrl) =>
    apiFetch<LinkOpaqueStartResponse>({ baseUrl, path: '/auth/v1/link/opaque/start', json: req, authMode: 'none' }),
  linkOpaqueFinish: (req, baseUrl) =>
    apiFetch<LinkOpaqueFinishResponse>({ baseUrl, path: '/auth/v1/link/opaque/finish', json: req, authMode: 'none' }),
  linkPasskeyStart: (req, baseUrl, _accessToken) =>
    // accessToken is injected via the session store inside apiFetch — the
    // ServerClient signature passes it explicitly so the crypto package
    // can be tested with a mock that does not depend on the store.
    apiFetch<LinkPasskeyStartResponse>({ baseUrl, path: '/auth/v1/link/passkey/start', json: req, authMode: 'bearer' }),
  linkPasskeyFinish: (req, baseUrl, _accessToken) =>
    apiFetch<LinkPasskeyFinishResponse>({ baseUrl, path: '/auth/v1/link/passkey/finish', json: req, authMode: 'bearer' }),
  loginOpaqueStart: (req, baseUrl) =>
    apiFetch<OpaqueLoginStartResponse>({ baseUrl, path: '/auth/v1/opaque/login/start', json: req, authMode: 'none' }),
  loginOpaqueFinish: (req, baseUrl) =>
    apiFetch<OpaqueLoginFinishResponse>({ baseUrl, path: '/auth/v1/opaque/login/finish', json: req, authMode: 'none' }),
  recoveryStart: (req, baseUrl) =>
    apiFetch<RecoveryStartResponse>({ baseUrl, path: '/auth/v1/recovery/start', json: req, authMode: 'none' }),
  recoveryFinish: (req, baseUrl) =>
    apiFetch<RecoveryFinishResponse>({ baseUrl, path: '/auth/v1/recovery/finish', json: req, authMode: 'none' }),
  deleteMe: (baseUrl, _accessToken) =>
    apiFetch<void>({ baseUrl, path: '/auth/v1/me', method: 'DELETE', authMode: 'bearer' }),
};
```

**Implementation note (ADR 0021 — OPAQUE-first linking):** `/v1/link/passkey/{start,finish}` is bearer-only and refuses passkey-first registration on a fresh account. Codified in [ADR 0021](../../obsidian/decisions/0021-phase0-opaque-first-linking.md); spec §4 was amended to match. Task 9's linking flow is OPAQUE-first followed by an *optional* passkey add on the same screen. There is no two-flow branching in the UI.

- 429 produces an `HttpError` with `retryAfterSeconds`.
- The `httpServerClient` is a drop-in for `packages/crypto`'s `ServerClient` interface.

The session store holds a single `MasterKeySession | null` reference. On `close()` the session zeroes its in-RAM buffers (`packages/crypto` `session.ts`). The store exposes `closeAndForget()` for the fetch wrapper to call when refresh fails. The store never persists to storage — `localStorage` and `sessionStorage` are off-limits per CLAUDE.md §14.

The connectivity store implements the state machine in spec §7.3. Transitions happen from three sources: `navigator.onLine` events, server outcomes from `loginOnlineLinked`, and fetch-wrapper outcomes (5xx = unreachable; 401 = auth_failed).

```typescript
// apps/user-client/src/state/session.store.ts
// SPDX-License-Identifier: AGPL-3.0-only
import type { MasterKeySession } from '@chatsundere/crypto';
import { create } from 'zustand';

interface SessionState {
  session: MasterKeySession | null;
  setSession(session: MasterKeySession): void;
  updateAccessToken(token: string): void;
  closeAndForget(): void;
}

export const useSessionStore = create<SessionState>((set, get) => ({
  session: null,
  setSession: (session) => set({ session }),
  updateAccessToken: (token) => {
    const current = get().session;
    if (!current) return;
    // MasterKeySession is readonly in its public shape but our app-level
    // wrapper allows token rotation. We replace the reference with one
    // that points at the same MK but with a new token. The session's
    // close() still works because we proxy it through.
    set({ session: { ...current, accessToken: token } as MasterKeySession });
  },
  closeAndForget: () => {
    const s = get().session;
    s?.close();
    set({ session: null });
  },
}));
```

**Decision (Chris-approved):** define `AppSession = MasterKeySession & { accessToken?: string }` in `state/session.store.ts` and never re-wrap. The fetch wrapper rotates `accessToken` on this app-layer alias; the crypto package's `MasterKeySession` type stays untouched (crypto purity rule — CLAUDE.md §3 hard rule that the auth layer is the wrapper, not the keystore).

```typescript
// apps/user-client/src/state/connectivity.store.ts
// SPDX-License-Identifier: AGPL-3.0-only
import { create } from 'zustand';

export type Connectivity =
  | { kind: 'local_offline' }      // no linked account; not online
  | { kind: 'local_online' }       // no linked account; online (link available)
  | { kind: 'linked_online' }      // linked + server reachable
  | { kind: 'server_unreachable' } // linked + server 5xx / timeout
  | { kind: 'server_auth_failed' };// linked + server 401

interface ConnectivityState {
  state: Connectivity;
  setState(s: Connectivity): void;
  onNetworkOnline(): void;
  onNetworkOffline(): void;
  onServerOk(): void;
  onServerUnreachable(): void;
  onServerAuthFailed(): void;
}

export const useConnectivityStore = create<ConnectivityState>((set, get) => ({
  state: { kind: 'local_offline' },
  setState: (state) => set({ state }),
  onNetworkOnline: () => {
    const s = get().state;
    if (s.kind === 'local_offline') set({ state: { kind: 'local_online' } });
    // Other linked transitions wait for the next server interaction.
  },
  onNetworkOffline: () => {
    const s = get().state;
    if (s.kind === 'linked_online' || s.kind === 'server_auth_failed' || s.kind === 'server_unreachable')
      set({ state: { kind: 'server_unreachable' } });
    if (s.kind === 'local_online') set({ state: { kind: 'local_offline' } });
  },
  onServerOk: () => set({ state: { kind: 'linked_online' } }),
  onServerUnreachable: () => set({ state: { kind: 'server_unreachable' } }),
  onServerAuthFailed: () => set({ state: { kind: 'server_auth_failed' } }),
}));

/** Call once at boot. */
export function attachConnectivityListeners(): void {
  if (typeof window === 'undefined') return;
  window.addEventListener('online', () => useConnectivityStore.getState().onNetworkOnline());
  window.addEventListener('offline', () => useConnectivityStore.getState().onNetworkOffline());
  if (!navigator.onLine) useConnectivityStore.getState().onNetworkOffline();
}
```

```typescript
import { useMemo } from 'react';

export function BreathingOrb({ seed }: { seed?: number }) {
  // Deterministic per mount when no seed; jitter is per-instance.
  const params = useMemo(() => {
    const rng = seedRandom(seed ?? Math.random() * 1e9);
    return {
      size: 140 + rng() * 220,
      top: rng() * 100,
      left: rng() * 100,
      period: 7 + rng() * 6,
      drift: 12 + rng() * 18,
    };
  }, [seed]);
  return (
    <div
      aria-hidden
      className="pointer-events-none absolute rounded-full blur-3xl opacity-40 mix-blend-screen"
      style={{
        width: params.size, height: params.size,
        top: `${params.top}%`, left: `${params.left}%`,
        background: 'radial-gradient(circle, var(--color-aurora-500), transparent 70%)',
        animation: `breathe ${params.period}s ease-in-out infinite alternate`,
        ['--drift' as const]: `${params.drift}px`,
      }}
    />
  );
}

function seedRandom(s: number) {
  let v = s;
  return () => {
    v = (v * 9301 + 49297) % 233280;
    return v / 233280;
  };
}
```

```typescript
// apps/user-client/src/lib/validators.ts
// SPDX-License-Identifier: AGPL-3.0-only
import { validateUsername } from '@chatsundere/crypto';
import * as v from 'valibot';

/**
 * Re-export — keeps validation logic in exactly one place.
 * Throws `CryptoError('invalid_input', ...)` on failure.
 */
export { validateUsername };

export const PassphrasePair = v.pipe(
  v.object({
    passphrase: v.pipe(v.string(), v.minLength(8, 'At least 8 characters.')),
    confirmation: v.string(),
  }),
  v.check((p) => p.passphrase === p.confirmation, 'Passphrases must match.'),
);

/** Crockford base32 with separators and checksum; details validated by packages/crypto. */
export const RecoveryKeyLike = v.pipe(
  v.string(),
  v.transform((s) => s.toUpperCase().replace(/[\s-]+/g, '')),
  v.minLength(50, "That doesn't look like a full recovery key."),
);

export interface PassphraseStrength {
  score: 0 | 1 | 2 | 3 | 4;
  hint: string;
}

/** Simple informational meter — not a gate. */
export function scorePassphrase(p: string): PassphraseStrength {
  let bits = 0;
  if (/[a-z]/.test(p)) bits += 26;
  if (/[A-Z]/.test(p)) bits += 26;
  if (/\d/.test(p)) bits += 10;
  if (/[^A-Za-z0-9]/.test(p)) bits += 32;
  const entropy = (p.length * Math.log2(Math.max(bits, 2)));
  if (entropy < 28) return { score: 0, hint: 'Too short to be safe.' };
  if (entropy < 36) return { score: 1, hint: 'Could be guessed.' };
  if (entropy < 60) return { score: 2, hint: 'Acceptable.' };
  if (entropy < 90) return { score: 3, hint: 'Strong.' };
  return { score: 4, hint: 'Excellent.' };
}
```

```typescript
import { useEffect, useState } from 'react';

export function Login() {
  const navigate = useNavigate();

  const [biometricAvailable, setBiometricAvailable] = useState<PasskeyCredentialRow[]>([]);
  const [passphrase, setPassphrase] = useState('');
  const [submitting, setSubmitting] = useState(false);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {

      const linkedRow = await getLinkedAccount(db);

      const passkeys = await listLocalBiometric(db);

    setSubmitting(true); setError(null);

      const db = getDb();

        const { session, serverOutcome } = await loginOnlineLinked({ db, serverClient: httpServerClient, passphrase });
        useSessionStore.getState().setSession(session);
        mapOutcome(serverOutcome);

        useSessionStore.getState().setSession(session);
      }
      navigate('/app', { replace: true });
    } catch (e) {
      setError(e instanceof Error ? e.message : 'Wrong passphrase.');
    } finally {
      setSubmitting(false);
    }
  }

  async function submitBiometric(passkey: PasskeyCredentialRow) {
    setSubmitting(true); setError(null);
    try {
      const result = await loginWithLocalBiometric({ db: getDb(), credentialId: passkey.credential_id });
      useSessionStore.getState().setSession(result.session);
      navigate('/app', { replace: true });

    } finally {

    }

  return (

      </div>
      {error && <p className="mt-3 text-sm text-danger">{error}</p>}

        className="mt-4 w-full rounded-[var(--radius-card)] bg-ink-soft px-6 py-3 font-mono uppercase tracking-wider ring-1 ring-inset ring-aurora-700/40">
        {submitting ? 'Unlocking…' : 'Unlock'}
```

```typescript
// apps/user-client/src/lib/webauthn.ts (sketch — implementation in Task 10)
// SPDX-License-Identifier: AGPL-3.0-only
import {
  PRF_INPUT_SALT, completeLocalBiometricRegistration,
} from '@chatsundere/crypto';
import { getDb } from '../boot/open-db.js';
import { useSessionStore } from '../state/session.store.js';

/** Per ADR 0005 — refuse passkeys without PRF. */
export class PrfRequiredError extends Error {
  constructor() { super("This device's biometric system doesn't support the secure key derivation Chatsundere needs. Try another device."); }
}

export async function registerLocalBiometric(label: string): Promise<void> {
  const session = useSessionStore.getState().session;
  if (!session) throw new Error('No active session.');
  const challenge = crypto.getRandomValues(new Uint8Array(32));
  const credential = await navigator.credentials.create({
    publicKey: {
      challenge,
      rp: { id: window.location.hostname, name: 'Chatsundere' },
      user: { id: new TextEncoder().encode(session.userId), name: session.username, displayName: session.username },
      pubKeyCredParams: [{ alg: -8, type: 'public-key' }, { alg: -7, type: 'public-key' }],
      authenticatorSelection: { residentKey: 'preferred', userVerification: 'required' },
      extensions: { prf: { eval: { first: PRF_INPUT_SALT } } },
    },
  }) as PublicKeyCredential | null;
  if (!credential) throw new Error('Biometric registration was cancelled.');
  const ext = credential.getClientExtensionResults() as { prf?: { enabled?: boolean; results?: { first?: ArrayBuffer } } };
  if (!ext.prf?.enabled || !ext.prf.results?.first) throw new PrfRequiredError();
  await completeLocalBiometricRegistration({
    db: getDb(), mk: session as never /* exposes mk reference per packages/crypto contract */,
    credential, prfOutput: new Uint8Array(ext.prf.results.first), label,
  });
}
```

```typescript
// apps/user-client/src/lib/motion.ts
// SPDX-License-Identifier: AGPL-3.0-only

/** Deterministic mulberry32; ok for visuals, never for cryptography. */
export function seedRandom(seed: number): () => number {
  let v = seed | 0;
  return () => {
    v = (v + 0x6d2b79f5) | 0;
    let t = v;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

export function pickWithin(rng: () => number, min: number, max: number): number {
  return min + rng() * (max - min);
}

export function respectsReducedMotion(): boolean {
  if (typeof window === 'undefined') return true;
  return window.matchMedia('(prefers-reduced-motion: reduce)').matches;
}
```
